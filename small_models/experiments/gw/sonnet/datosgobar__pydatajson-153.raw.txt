It also assumes `tests/samples/full_data.json` has at least two datasets.

- **Empty list:** `test_empty_dataset_list_harvests_nothing` fails on the current code because an empty list is treated as "all datasets", so `harvest_dataset_to_ckan` gets called.
- **Failure handling:** `test_failure_in_one_dataset_does_not_stop_the_rest` fails on the current code because the first call raises and nothing catches it. After the fix, every dataset should still be attempted.
- **Existing behaviour:** `test_none_dataset_list_harvests_all` should pass both before and after the fix. It only guards that `None` still means "harvest everything".

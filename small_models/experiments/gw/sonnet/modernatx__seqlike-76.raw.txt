I could not read `seqlike/codon_tables.py`, so this test is written from the issue and has not been run. It assumes the module mutates the table from `pct.get_codons_table(...)` at import time, which is where the pollution would come from. It checks that `python_codon_tables` returns an unmodified 21-key table after `seqlike.codon_tables` is imported and reloaded. If the mutation happens inside a function instead, the test will not catch it.

+        pass

+        table1.pop("-", None)
+        table1.pop("X", None)

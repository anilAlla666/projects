I haven't run these tests against the repository, so they are untested. They assume `Collection` accepts a `collection_info` dict and that the `taxii2client` module exports `MEDIA_TYPE_STIX_V20` and `MEDIA_TYPE_TAXII_V20`. I couldn't confirm either from memory of the codebase.

The tests build a `Collection` whose URL has no trailing slash and mock the endpoints with `responses`. The mocked URLs always include the slash, so on the current code the client requests `.../<id>objects/...` and gets a connection error from `responses`. Once the client adds the missing slash, the requests reach the mocked URLs and the tests pass. Passing `collection_info` avoids a lazy load of the collection, so the mocks only need to cover the objects and manifest endpoints.

I couldn't see the repository, so these tests are written without knowing how `sensorhub/hub.py` is laid out. I've assumed the bus library is imported as `smbus2` or `smbus` and replaced both with mocks, so the tests need no I/O hardware. I haven't run them.

The first test fails on the current code because `SensorHub()` raises a `TypeError` when the bus argument is missing. It should pass once that argument has a default. The second test checks that passing an explicit bus still works.

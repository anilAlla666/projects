I've added a test to `control/tests/sisotool_test.py`. It turns Matplotlib deprecation warnings into errors while `sisotool` runs. I haven't run it.

On the current code it should fail with Matplotlib 3.6 or later, because `ax_phase.get_shared_x_axes().join(...)` raises the `join` deprecation warning. It should pass once `sisotool.py` stops using `join()`, for example by calling `ax_phase.sharex(ax_mag)` instead. On Matplotlib older than 3.6 the warning doesn't exist, so the test passes either way.

The test also checks that the Bode magnitude and phase axes still share their x-axis. It finds the magnitude and phase axes by their y-labels, which assumes the plot labels them `Magnitude` and `Phase`. If sisotool's labels differ, the axes lookup will find nothing and the test will fail on that assertion rather than on the warning.

+import warnings

+def test_sisotool_no_matplotlib_deprecation_warning():
+    """sisotool must not use deprecated Matplotlib API (e.g., Grouper.join)."""
+    from control import tf
+    from control.sisotool import sisotool
+
+    plt.close('all')
+    sys = tf([1000], [1, 25, 100, 0])
+    with warnings.catch_warnings():
+        warnings.simplefilter(
+            "error", category=matplotlib.MatplotlibDeprecationWarning)
+        sisotool(sys)
+
+    # magnitude and phase axes should still share the x axis
+    fig = plt.gcf()
+    mag = [ax for ax in fig.axes if ax.get_ylabel().startswith('Magnitude')]
+    phase = [ax for ax in fig.axes if ax.get_ylabel().startswith('Phase')]
+    assert mag and phase
+    assert phase[0].get_shared_x_axes().joined(phase[0], mag[0])
+    plt.close('all')

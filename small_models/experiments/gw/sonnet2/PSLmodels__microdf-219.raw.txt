The tests cover these cases:
- **Boolean `MicroSeries` mask:** after `d[d.y > 1]`, the weights have shape `(2,)` and values `[5, 6]`.
- **NumPy boolean mask:** the same expected weights.
- **`.loc` mask:** the same expected weights.
- **Means on the subset:** `d2.x.mean()` is `28/11`, and `d[d.y > 1].mean()` works without the `TypeError`.
- **Column selection:** `d[["x"]]` keeps all three weights.
- **Original frame:** it is left unchanged after a subset.
- **`MicroSeries`:** the existing behaviour is pinned.

The `.loc` and column-selection tests may already pass on the current code. The mask tests, the mean tests and the original-frame check should fail on it, since they rely on the weights being subset.

+import numpy as np
+
+import microdf as mdf
+
+
+def _make():
+    return mdf.MicroDataFrame(
+        {"x": [1, 2, 3], "y": [1, 2, 2]}, weights=[4, 5, 6]
+    )
+
+
+def test_boolean_series_subset_weights_shape():
+    d = _make()
+    d2 = d[d.y > 1]
+    assert d2.shape == (2, 2)
+    assert np.array(d2.weights).shape == (2,)
+
+
+def test_boolean_series_subset_weights_values():
+    d = _make()
+    d2 = d[d.y > 1]
+    np.testing.assert_array_equal(np.array(d2.weights), [5, 6])
+
+
+def test_numpy_mask_subset_weights():
+    d = _make()
+    d2 = d[np.array([False, True, True])]
+    assert d2.shape == (2, 2)
+    np.testing.assert_array_equal(np.array(d2.weights), [5, 6])
+
+
+def test_loc_mask_subset_weights():
+    d = _make()
+    d2 = d.loc[d.y > 1]
+    np.testing.assert_array_equal(np.array(d2.weights), [5, 6])
+
+
+def test_subset_column_mean_uses_subset_weights():
+    d = _make()
+    d2 = d[d.y > 1]
+    np.testing.assert_allclose(d2.x.mean(), (2 * 5 + 3 * 6) / 11)
+
+
+def test_subset_dataframe_mean_does_not_raise():

I've added a unit test for `tools.get_brew_url` that mocks the two Brew calls and checks the dot in the artifact name is kept in the generated URL. I haven't run it. I'm assuming the function is called `get_brew_url(md5)` and that it calls `subprocess.check_output` twice, first `listArchives`, then `getBuild`. The first part of the function wasn't visible, so check those against the real code.

The test feeds in the `javax.json` archive from the issue. It expects the group id `org.glassfish` to become `org/glassfish` and the artifact id `javax.json` to stay unchanged. On the current code the artifact id is turned into `javax/json`, so the test fails there.

I'm adding tests to `tests/test_model.py`. I haven't run them. They cover the behaviour the issue specifies and leave its open points alone.

The tests check that:
- Assigning a new key adds a field to the entry.
- The new field's key is the assigned string and its value is the assigned value, and it is a `Field` instance.
- Assigning an existing key replaces that field rather than adding a duplicate.
- Assigning a non-string value (an int) is stored as given.

I do not test how `ENTRYTYPE` or `ID` assignment behaves, because the issue does not specify it.

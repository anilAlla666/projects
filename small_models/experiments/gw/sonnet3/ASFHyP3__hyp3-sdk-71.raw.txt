I'll add tests to `tests/test_jobs.py` that check `Batch` iteration through the public interface only. They don't depend on whether the fix uses `__iter__` or `__getitem__`, since both make a `Batch` iterable.

The tests cover:
- Iterating a batch yields the same jobs, in the same order.
- Iterating an empty batch yields nothing.
- A list comprehension over a batch works, which is the usage in the issue.
- Iterating the same batch twice works.

I don't test indexing, because the issue doesn't ask for it. The first test builds jobs from `SUCCEEDED_JOB`, whose `files` entry has a size of 5949932, and iterates a `Batch` containing them.

I'm adding a regression test to `test/test_CppHeaderParser.py`, placed before the `if __name__` block. I have not run it against the current code or a fix.

The header from the issue has no trailing semicolon after the class. The test uses the same header, since that is what triggers the `KeyError`. It only asserts things the issue clearly implies: parsing completes without raising, and the class `B` and its method `aMethod` exist. It does not assert what `rtnType` resolves to, because the issue leaves that open (it could stay `A` or become `C`).

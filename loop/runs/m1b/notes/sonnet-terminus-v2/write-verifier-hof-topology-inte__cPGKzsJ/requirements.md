# Requirements extracted from task instructions

- R1. Output location and format: "Write `/app/solution/output.json` as a JSON object keyed by the file stem (filename without the `.cif` extension)."
- R2. Coverage of keys: the JSON object must be keyed by the stem of every HOF CIF file provided in `/app/data` ("the HOFs provided as Crystallographic Information Files (CIFs) in `/app/data`", combined with R1's "keyed by the file stem"). No missing HOF and no fabricated extra keys not corresponding to a CIF in `/app/data`.
- R3. Value shape: "Each value is an array of four elements, in this exact order": (1) topology string, (2) interpenetration integer, (3) average internodal distance number, (4) coordination sequence array. Order and count (exactly 4 elements) must be respected.
- R4. Topology field type/content: "the topology in the RCSR naming scheme (string)" — must be a string (an RCSR three-letter/symbol-style net name).
- R5. Interpenetration field type: "the degree of interpenetration (integer)" — must be an integer (not a float, string, or null), and by definition of interpenetration (number of independent interpenetrating nets) must be a positive integer (>=1).
- R6. Average internodal distance field: "the average internodal distance in nanometers, rounded to two decimal places, excluding the unit symbol (number)" — must be a plain number (no units/string), expressed in nanometers, and rounded to exactly two decimal places.
- R7. Coordination sequence field: "the coordination sequence of the underlying net, given as a JSON array of its first six terms (six integers)" — must be a JSON array of exactly six integers.
- R8. Definition of hydrogen bond used to build the network: "A hydrogen bond is identified geometrically as a donor–acceptor (D···A) distance of at most 3.5 Å together with a D–H···A angle of at least 120°, where the donor (D) and acceptor (A) are electronegative atoms (N, O, F)." The network (and therefore all downstream quantities: nodes, edges, topology, interpenetration, distances, coordination sequence) must be built exclusively from bonds satisfying this exact geometric criterion (distance <= 3.5 Å, angle >= 120°, D/A in {N,O,F}).
- R9. Exclusivity of the network definition: "For every HOF the network is defined exclusively by intermolecular hydrogen bonds." Only intermolecular H-bonds define the network; intramolecular H-bonds must not be used to create network edges.
- R10. Non-framework molecules ignored: "Molecules that do not contribute to the hydrogen-bonded framework must be ignored." Solvent/guest molecules or isolated molecules not part of the connected H-bonded framework must not be counted as nodes or otherwise affect the topology/interpenetration/distance/coordination-sequence results.
- R11. Node definition — general: "A node of the topological network is a point at which three or more framework molecules are joined together by hydrogen bonding." A vertex of the net must correspond to a junction of at least three framework molecules (degree/connectivity >= 3 in terms of molecules joined).
- R12. Node definition — molecular node: "Molecular node: The geometric centroid of a multitopic framework molecule, that is, a molecule whose hydrogen bonds connect it to three or more neighbouring molecules." When a single molecule is hydrogen-bonded to >=3 neighbouring molecules, the node is placed at that molecule's geometric centroid.
- R13. Node definition — supramolecular/cluster node: "Supramolecular (cluster) node: The geometric centroid of a discrete hydrogen-bonded cluster of functional groups in which three or more framework molecules converge and associate through mutual hydrogen bonding of their terminal groups... the cluster as a whole is the node, and each molecule that contributes a terminal group to the cluster contributes exactly one edge to it." When >=3 molecules converge through mutual H-bonding of terminal groups (no single molecule sitting at the junction), the node is placed at the cluster's geometric centroid, and each contributing molecule supplies exactly one edge to that node.
- R14. Both node kinds may coexist: "A single network may contain both kinds at once... If two kinds of node are present, you must consider both." The solver must not omit either kind of node if both occur in a given HOF's network.
- R15. Edge (non-node, degree-2 linker) definition: "A framework molecule that is hydrogen-bonded to exactly two other molecules, or that contributes only to two nodes, is treated as a single edge between those two nodes and is not itself a node." Molecules of exactly degree 2 (bridging exactly two nodes) must be represented as edges, not as vertices of the topological net.
- R16. Average internodal distance definition and scope: "The average internodal distance is the mean Euclidean distance, in nanometers, between pairs of nodes (of either kind) that are either directly connected in the resulting network, or connected via a single edge (a molecule or group that links exactly two nodes)." The averaging must be over exactly the set of node pairs that are network-adjacent (directly bonded node-to-node) or bridged by exactly one degree-2 linker molecule/group — not over all node pairs in the structure, and not restricted only to direct H-bond contacts while ignoring degree-2-linked pairs.
- R17. Coordination sequence definition: "The coordination sequence is the translation invariant [c1,...] in which c_k is the number of distinct vertices of the periodic net whose shortest topological path (counted in number of edges) to a fixed reference vertex is exactly k edges long." This must be computed on the underlying topological net (nodes/edges as defined by R11-R15), using graph-distance (edge count), not Euclidean distance.
- R18. Coordination sequence reference-vertex independence assumption: "Report one such sequence per framework; for every net in this dataset the coordination sequence does not depend on the choice of reference vertex." Only one coordination sequence (6 integers) is required per HOF (not per distinct vertex type), consistent with vertex-transitivity of the reported net for this dataset.
- R19. Rounding requirement restated: "rounded to two decimal places" applies specifically to the average internodal distance value (R6); other numeric fields (interpenetration integer, coordination sequence integers) must remain exact integers, not rounded floats.
- R20. Units requirement: average internodal distance must be reported "in nanometers" (not Angstroms or other units), and "excluding the unit symbol" (i.e., a bare number, no 'nm' suffix or units string).
- R21. No online/task-specific-hint solving: "Do not cheat by using online solutions or hints specific to this task." (This constrains how the *solver* must work; while not directly machine-checkable from the output file alone, it is listed here for completeness as a stated requirement.)

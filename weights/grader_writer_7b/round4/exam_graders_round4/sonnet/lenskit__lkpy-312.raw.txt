I've added one test file covering both faults from the issue. I have not run it against the current code or a fix.

- **No `k`, recs shorter than truth:** `test_ndcg_no_k_truncates_truth_to_recs` expects 8/9 ≈ 0.8888 for recs `[1, 2]`, matching the issue's expected value. It also checks that omitting `k` gives the same result as `k=2`.
- **`k` shorter than recs:** `test_ndcg_k_truncates_recs` expects 1.0 for recs `[2, 3, 1]` with `k=2`, and the same for the pre-truncated list `recs[:2]`.
- **`k` longer than recs:** `test_ndcg_k_larger_than_recs` expects the same 8/9 for recs `[1, 2]` with `k=5`.
- **Unrated truth (no `rating` column):** `test_ndcg_no_rating_no_k_truncates` expects 1.0 for truth `[1, 2, 3]` and recs `[1, 2]`. The issue only shows the rated case, so this one assumes the ideal list is also cut to the recommendation length when there are no ratings. The issue doesn't state that case; drop this test if you don't want to pin it down.

+import numpy as np
+import pandas as pd
+
+from pytest import approx
+
+from lenskit.metrics.topn import ndcg
+
+
+def _truth():
+    truth = pd.DataFrame({'item': [1, 2, 3], 'rating': [3.0, 5.0, 4.0]})
+    return truth.set_index('item')
+
+
+def test_ndcg_no_k_truncates_truth_to_recs():
+    truth = _truth()
+    recs = pd.DataFrame({'item': [1, 2]})
+
+    # ideal over 2 items: 5 + 4 = 9; achieved: 3 + 5 = 8
+    assert ndcg(recs, truth, k=2) == approx(8 / 9)
+    assert ndcg(recs, truth) == approx(8 / 9)
+
+
+def test_ndcg_k_truncates_recs():
+    truth = _truth()
+    recs = pd.DataFrame({'item': [2, 3, 1]})
+
+    assert ndcg(recs, truth) == approx(1.0)
+    assert ndcg(recs[:2], truth, k=2) == approx(1.0)
+    assert ndcg(recs, truth, k=2) == approx(1.0)
+
+
+def test_ndcg_k_larger_than_recs():
+    truth = _truth()
+    recs = pd.DataFrame({'item': [1, 2]})
+
+    assert ndcg(recs, truth, k=5) == approx(8 / 9)
+
+
+def test_ndcg_no_rating_no_k_truncates():
+    truth = pd.DataFrame({'item': [1, 2, 3]}).set_index('item')
+    recs = pd.DataFrame({'item': [1, 2]})
+
+    assert ndcg(recs, truth, k=2) == approx(1.0)
+    assert ndcg(recs, truth) == approx(1.0)

I'm adding a new test file covering the issue's example. I haven't run these tests against the current code or a fix.

The tests check that boolean-mask subsetting of a `MicroDataFrame` carries the matching weights, and that `mean()` on the subset works. They also check that column selection still keeps the full weights, and that a column taken from the subset has weights matching its length.

I compare weights by value (`.values`) rather than by index. This is because the issue doesn't say whether the subset keeps the original index or resets it.

One assumption: `d[d.y > 1].mean()` returns something I can check by position, so I take `.iloc[0]` of the result for the `x` value. The expected weighted mean of `x` over rows 2 and 3 is (2·5 + 3·6) / 11 = 28/11. If `mean()` returns a plain scalar for one column, the test would need adjusting, but for a two-column frame it should return a Series.

```diff
--- /dev/null
+++ b/microdf/tests/test_subset_weights.py
@@ -0,0 +1,50 @@
+import numpy as np
+import microdf as mdf
+
+
+def _make():
+    return mdf.MicroDataFrame(
+        {"x": [1, 2, 3], "y": [1, 2, 2]}, weights=[4, 5, 6]
+    )
+
+
+def test_boolean_subset_weights_shape():
+    d = _make()
+    d2 = d[d.y > 1]
+    assert d2.shape == (2, 2)
+    assert d2.weights.shape == (2,)
+    assert np.array_equal(np.asarray(d2.weights.values), [5, 6])
+
+
+def test_boolean_subset_column_weights():
+    d = _make()
+    d2 = d[d.y > 1]
+    assert d2.x.shape == (2,)
+    assert d2.x.weights.shape == (2,)
+    assert np.array_equal(np.asarray(d2.x.weights.values), [5, 6])
+    assert np.isclose(d2.x.sum(), 2 * 5 + 3 * 6)
+    assert np.isclose(d2.x.mean(), (2 * 5 + 3 * 6) / 11)
+
+
+def test_boolean_subset_mean():
+    d = _make()
+    m = d[d.y > 1].mean()
+    assert np.isclose(m["x"], (2 * 5 + 3 * 6) / 11)
+    assert np.isclose(m["y"], 2)
+
+
+def test_boolean_subset_sum():
+    d = _make()
+    s = d[d.y > 1].sum()
+    assert np.isclose(s["x"], 2 * 5 + 3 * 6)
+    assert np.isclose(s["y"], 2 * 5 + 2 * 6)
+
+
+def test_column_subset_keeps_weights():
+    d = _make()
+    d2 = d[["x"]]
+    assert np.array_equal(np.asarray(d2.weights.values), [4, 5, 6])
+
+
+def test_series_subset_still_works():
+    s = mdf.MicroSeries([1, 2, 3], weights=[4, 5, 6])
+    s2 = s[s > 1]
+    assert s2.shape == (2,)
+    assert s2.weights.shape == (2,)
```

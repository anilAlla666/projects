The tests below check the Capturs parser's registered callsign directly. I have not run them.

On the current code, `Capturs.__destto__` is `['OGLT24', 'OGLT24-1']`. Because `Capturs` is defined after `LiveTrack24`, it also overwrites `LiveTrack24`'s entries in the parser registry. That is why one test also checks that `OGLT24` still maps to `LiveTrack24`.

The registry tests assume `ParserBase.parsers` stores the parser class itself as the value, which I inferred from the existing tests but did not confirm. If it stores something else, those two assertions would need adjusting.

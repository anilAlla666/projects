I've added a new test file covering the issue. I haven't run it, so it's untested against the current code and any fix.

The tests render through `mistune.Markdown` with a `ConfluenceRenderer(enable_relative_links=True)`. They check that a fragment-only link like `#frequently-asked-questions-osep` is not recorded as a relative link and does not get an `md2cf-internal-link` placeholder. The fix may leave the href as-is or convert it to a Confluence anchor, so the tests don't pin the output format beyond the fragment text appearing.

Two further tests guard against regressions. One checks that a relative link to another file, with or without a fragment, is still recorded. The other checks that an absolute URL is untouched.

I assumed the mistune 0.8-style API (`mistune.Markdown(renderer=...)`) and the new file path `tests/unit/test_anchor_links.py`.

+import mistune
+
+from md2cf.confluence_renderer import ConfluenceRenderer
+
+
+def render(markdown_text):
+    renderer = ConfluenceRenderer(enable_relative_links=True)
+    converter = mistune.Markdown(renderer=renderer)
+    output = converter(markdown_text)
+    return renderer, output
+
+
+def test_fragment_only_link_is_not_relative_link():
+    renderer, output = render(
+        "[Frequently Asked Questions](#frequently-asked-questions-osep)\n"
+    )
+
+    assert renderer.relative_links == []
+    assert "md2cf-internal-link" not in output
+    assert "frequently-asked-questions-osep" in output
+
+
+def test_multiple_fragment_only_links_not_relative():
+    renderer, output = render("[A](#a) and [B](#b-section)\n")
+
+    assert renderer.relative_links == []
+    assert "md2cf-internal-link" not in output
+
+
+def test_relative_link_to_file_still_detected():
+    renderer, output = render("[Other](other.md)\n")
+
+    assert len(renderer.relative_links) == 1
+    link = renderer.relative_links[0]
+    assert link.path == "other.md"
+    assert link.replacement in output
+
+
+def test_relative_link_to_file_with_fragment_still_detected():
+    renderer, output = render("[Other](other.md#some-section)\n")
+
+    assert len(renderer.relative_links) == 1
+    link = renderer.relative_links[0]
+    assert link.path == "other.md"
+    assert link.fragment == "some-section"
+
+
+def test_absolute_link_untouched():
+    renderer, output = render("[Site](https://example.com/page)\n")
+
+    assert renderer.relative_links == []
+    assert "https://example.com/page" in output

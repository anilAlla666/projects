I've added a test file that checks `_escape` and `_make_path` with byte-string arguments, which is the case the issue reports. I haven't run it against the current code or a fix. It is written so that `_escape(b'...')` raises `AttributeError` on Python 3 today and should pass once bytes are handled.

- **`_escape` with ASCII bytes:** it must not raise and must return a value equal to the original bytes.
- **`_escape` with non-ASCII bytes:** the UTF-8 bytes `\xc3\xa9` must come back unchanged, so a fix cannot decode and re-encode them.
- **`_make_path` with bytes parts:** bytes index and type names, and the task-id string from the issue, must produce the same URL path as the equivalent text.
- **Regression checks:** text, unicode, list, bool and int arguments to `_escape` and `_make_path` must still behave as before.

I put the tests in a new top-level file, `test_elasticsearch/test_client_utils_bytes.py`, rather than assuming a `test_client` subdirectory exists.

```diff
--- /dev/null

+# -*- coding: utf-8 -*-
+from __future__ import unicode_literals
+
+from elasticsearch.client.utils import _escape, _make_path
+
+from .test_cases import TestCase
+
+
+class TestEscapeBytes(TestCase):
+    def test_escape_bytes_does_not_raise(self):
+        self.assertEqual(
+            b'celery-task-meta-c4f1201f',
+            _escape(b'celery-task-meta-c4f1201f'))
+
+    def test_escape_non_ascii_bytes_unchanged(self):
+        self.assertEqual(b'\xc3\xa9', _escape(b'\xc3\xa9'))
+
+    def test_escape_text_still_encoded(self):
+        self.assertEqual('abc'.encode('utf-8'), _escape('abc'))
+        self.assertEqual('é'.encode('utf-8'), _escape('é'))
+
+    def test_escape_list_and_bool_and_int(self):
+        self.assertEqual(b'a,b', _escape(['a', 'b']).encode('utf-8')
+                         if not isinstance(_escape(['a', 'b']), bytes)
+                         else _escape(['a', 'b']))
+        self.assertEqual('true', _escape(True))
+        self.assertEqual('1', _escape(1))
+
+
+class TestMakePathBytes(TestCase):
+    def test_make_path_with_bytes_parts(self):
+        self.assertEqual('/index/type/1',
+                         _make_path(b'index', b'type', 1))
+
+    def test_make_path_with_bytes_id_from_issue(self):
+        self.assertEqual(
+            '/index/doc/celery-task-meta-c4f1201f-eb7b-41d5-9318-a75a8cfbdaa0',
+            _make_path('index', 'doc',
+                       b'celery-task-meta-c4f1201f-eb7b-41d5-9318-a75a8cfbdaa0'))
+
+    def test_make_path_bytes_and_text_equal(self):
+        self.assertEqual(_make_path('idx', 'doc', 'abc'),
+                         _make_path(b'idx', b'doc', b'abc'))
+
+    def test_make_path_non_ascii_bytes(self):
+        self.assertEqual(_make_path('idx', 'é'),
+                         _make_path('idx', 'é'.encode('utf-8')))
+
+    def test_make_path_text_unchanged(self):
+        self.assertEqual('/i/%C3%A9', _make_path('i', 'é'))
```

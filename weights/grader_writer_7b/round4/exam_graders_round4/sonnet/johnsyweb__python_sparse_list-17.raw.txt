I'm adding a new test file with tests for deleting empty slices. I haven't run it against the code.

The current `__delitem__` reads `indices[0]` on an empty `xrange`, which raises `IndexError`. That is why `del sl[3:3]` fails.

The tests assert only that the list is unchanged after deleting an empty slice. They cover:
- an empty slice in the middle of a list;
- an empty slice at the start (`0:0`), at the end (`5:5`) and past the end (`10:10`);
- an inverted range (`4:2`);
- an empty slice on a list holding real elements;
- an empty slice on an empty list.

The python2 `__delslice__` path is exercised too, because `del sl[3:3]` goes through it on Python 2.

To check contents I compare `sl` against a plain list, as the existing tests do (e.g. `assertEqual([1, 2], sl)`). Plain `list.__eq__` returns `NotImplemented` for a `SparseList`, so Python falls back to the reflected comparison. I rely on that same pattern, so the new tests are no more fragile than the existing ones. To be safer, I also compare `list(sl)` and `sl.elements` directly.

I deliberately leave the exact `elements` content for non-empty cases alone. For an unchanged list, `elements` should equal what it was before, so I snapshot it with `dict(sl.elements)`.

+#!/usr/bin/env python
+
+import unittest
+import sparse_list
+
+try:
+    xrange
+except NameError:
+    xrange = range
+
+
+class TestDeleteEmptySlice(unittest.TestCase):
+    def test_delete_empty_slice_middle(self):
+        sl = sparse_list.SparseList(xrange(5), None)
+        del sl[3:3]
+        self.assertEqual(5, len(sl))
+        self.assertEqual([0, 1, 2, 3, 4], list(sl))
+
+    def test_delete_empty_slice_start(self):
+        sl = sparse_list.SparseList(xrange(5), None)
+        del sl[0:0]
+        self.assertEqual(5, len(sl))
+        self.assertEqual([0, 1, 2, 3, 4], list(sl))
+
+    def test_delete_empty_slice_end(self):
+        sl = sparse_list.SparseList(xrange(5), None)
+        del sl[5:5]
+        self.assertEqual(5, len(sl))
+        self.assertEqual([0, 1, 2, 3, 4], list(sl))
+
+    def test_delete_empty_slice_past_end(self):
+        sl = sparse_list.SparseList(xrange(5), None)
+        del sl[10:10]
+        self.assertEqual(5, len(sl))
+        self.assertEqual([0, 1, 2, 3, 4], list(sl))
+
+    def test_delete_empty_inverted_slice(self):
+        sl = sparse_list.SparseList(xrange(5), None)
+        del sl[4:2]
+        self.assertEqual(5, len(sl))
+        self.assertEqual([0, 1, 2, 3, 4], list(sl))
+
+    def test_delete_empty_slice_sparse_unchanged(self):
+        sl = sparse_list.SparseList(6, None)
+        sl[1] = 'a'
+        sl[4] = 'b'
+        before = dict(sl.elements)
+        del sl[3:3]
+        self.assertEqual(6, len(sl))
+        self.assertEqual(before, sl.elements)
+        self.assertEqual([None, 'a', None, None, 'b', None], list(sl))
+
+    def test_delete_empty_slice_on_empty_list(self):
+        sl = sparse_list.SparseList(0, None)
+        del sl[0:0]
+        self.assertEqual(0, len(sl))
+        self.assertEqual({}, sl.elements)
+
+    def test_delete_empty_slice_all_default(self):
+        sl = sparse_list.SparseList(5, None)
+        del sl[2:2]
+        self.assertEqual(5, len(sl))
+        self.assertEqual({}, sl.elements)
+
+
+if __name__ == '__main__':
+    unittest.main()

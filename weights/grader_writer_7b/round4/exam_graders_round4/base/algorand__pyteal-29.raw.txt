To address the issue of shadowing the Python keyword `int` when importing `pyteal`, we need to ensure that the submodule `pyteal.ast.int` does not interfere with the built-in `int` function. One way to achieve this is to rename the submodule to something else that does not conflict with Python keywords.

Here's a proposed solution:

1. Rename the submodule `pyteal.ast.int` to `pyteal.ast.teal_int`.
2. Update all references to `pyteal.ast.int` in the codebase to use the new name.

Let's implement this step-by-step.
